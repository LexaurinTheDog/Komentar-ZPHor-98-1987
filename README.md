# Komentář k zákonu č. 98/1987 Sb., o zvláštním příspěvku horníkům

Otevřený komentář k zákonu o zvláštním příspěvku horníkům — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; podmínky nároku, výše a doba poskytování, uplatnění a výplata, zánik a vrácení, povinnosti hornických organizací.

Konsolidované znění: dokument e-Sbírky `SB-1987-00098_2010-01-01`.
